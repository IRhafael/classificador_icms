Como conectar a SEFAZ neste computador
  1. Instale o Node.js 18 ou superior e baixe o ZIP do repositório do sistema pelo botão Code → Download ZIP no GitHub. Extraia a pasta completa; não basta salvar só o HTML.
  2. Abra o PowerShell dentro da pasta extraída e inicie o conector com a origem deste site: 
    $env:SEFAZ_ALLOWED_ORIGINS = 'https://irhafael.github.io'
node .\sefaz-bridge\server.mjs
  3. Na primeira execução, aguarde o conector baixar/verificar a cadeia ICP-Brasil. Deixe o PowerShell aberto e copie o valor impresso após Token desta execução:.
  4. Cole esse token no campo acima, escolha seu certificado A1 (.pfx/.p12), informe a senha e clique Conectar. O certificado precisa pertencer a contribuinte emitente de NF-e/NFC-e.
  5. Marque Consultar na SEFAZ pelo certificado para pesquisar. Cada pessoa que usar o site precisa iniciar o próprio conector e usar seu próprio certificado.

O token não vem da SEFAZ: o conector cria um código local ao iniciar para proteger a comunicação entre esta página e o programa no seu computador. Ele muda quando o conector reinicia. A SEFAZ autentica a consulta pelo certificado digital.

SEFAZ: consulta oficial do CCG (só GTINs brasileiros 789/790), exige o conector local rodando e certificado A1 de emitente de NF-e/NFC-e — o certificado fica só na memória do conector. Ordem de consulta: base própria → SEFAZ → PreçoMelhor. Só a base própria (XML de entrada) e a SEFAZ trocam o NCM; o PreçoMelhor aparece apenas como referência. Respostas ficam guardadas por 30 dias.
